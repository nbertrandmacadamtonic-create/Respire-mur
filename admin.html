Comment ça fonctionne

Modifiez les fiches puis exportez mur-content.json. Remplacez ce fichier dans GitHub. L'application chargera les nouveaux contenus.

Questionnaire ki.S

15 questions. Les réponses A / F / P doivent conserver leur ordre pour respecter le calcul actuel.

Bibliothèque d'exercices

Modifiez les titres, légendes, explications, illustrations et sons. Utilisez les noms exacts des fichiers GitHub.

Respiration guidée

Réglez les différentes phases en secondes et la durée totale des protocoles.

Inscriptions et utilisateurs

Pas encore de base centralisée. L'application conserve actuellement ses historiques sur les appareils des utilisateurs. GitHub Pages ne permet pas à lui seul de gérer de véritables inscriptions.

Activation des comptes

Une authentification et une base sécurisée seront nécessaires pour administrer les inscriptions. Les droits d'accès, la conservation des données et la conformité RGPD devront être définis.

Publier les modifications

Les changements sont conservés dans ce navigateur jusqu'à leur exportation.

Publication sur GitHub

  1. Exportez mur-content.json.
  2. Ouvrez le dépôt Respire-mur.
  3. Remplacez uniquement mur-content.json.
  4. Confirmez avec Commit changes.

Ne placez jamais de mots de passe, jetons GitHub ou données personnelles dans les fichiers publics.
