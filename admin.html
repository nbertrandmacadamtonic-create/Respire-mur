Comment ça fonctionne

Modifiez les fiches, puis exportez mur-content.json. Remplacez ce seul fichier dans votre dépôt GitHub. Les nouvelles données seront lues par mur-custom.js lors de l'ouverture de l'application.

Questionnaire ki.S

15 questions. Les trois choix A / F / P doivent rester dans le même ordre : ils alimentent le calcul actuel.

Bibliothèque d’exercices

Titre, sous-titre, explications, illustration et audio. Pour les images et sons, saisissez les noms exacts de fichiers présents sur GitHub.

Respiration guidée

Réglez les durées des phases en secondes et la durée totale de chaque protocole.

Inscriptions et utilisateurs

Pas encore de base d'utilisateurs centralisée. L'application M.U.R. actuelle conserve notamment l'historique sur l'appareil de chaque utilisateur. GitHub Pages ne peut pas collecter ni administrer les inscriptions à lui seul. Aucun compte, nombre d'inscrits ou donnée personnelle ne peut être présenté comme réel ici.

Pour activer les comptes

Il faudra connecter un service d'authentification et une base de données sécurisée (par exemple Supabase), définir les droits administrateurs, une politique de conservation et les mentions d'information RGPD. Les données liées au stress ou à la santé exigent une attention particulière. Cette rubrique sera raccordée uniquement après mise en place d'un backend sécurisé.

Publier les modifications

Les modifications sont conservées localement dans ce navigateur jusqu'à leur exportation ; elles ne sont pas envoyées automatiquement à GitHub.

Installation sur GitHub

  1. Ouvrez votre dépôt Respire-mur.
  2. Ajoutez une seule fois mur-custom.css, mur-custom.js et mur-content.json à la racine du dépôt.
  3. Vérifiez que index.html charge bien les deux fichiers personnalisés avant la fermeture de body.
  4. Pour chaque changement de contenu, remplacez mur-content.json par le nouveau fichier exporté, puis validez le commit.

Sécurité : ne placez jamais un jeton GitHub, un mot de passe ou des données de patients dans ce fichier public.
